# CollisionPro sample 3D vehicle models

These user-provided GLB models are included as sample assets for the 3D vehicle picker.

- Camry: `/models3d/camry.glb`
- F-150: `/models3d/f150.glb`

They are standalone static assets and can be loaded by the 3D picker using the **My account > 3D model library URL** setting with `/models3d` as the base. The automatic year/make/model filename lookup will not map these short sample names; use the direct URL or an exact shop-uploaded model entry when needed.
